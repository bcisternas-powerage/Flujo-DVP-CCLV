Etapa 2 — Ingreso al core y creación de la nómina

El canal notifica al core que hay una nómina para procesar. El core valida y crea la nómina, dejando la cabecera y el detalle en las tablas correspondientes, incluyendo los campos extendidos para DVP/CCLV.

Programa principal: ILBTR060 (Notificar al Core carga LBTR)

OpenAPI que notifica al core la existencia de un archivo/nómina. Clase ILBTR06001. Recibe tipo de interfaz, RUT empresa, nº de registros, monto total, cuenta de cargo, usuario e id de nómina.

El campo Tipo de Interfaz (posición 59 del archivo de entrada) define el producto: 1 = LBTR Archivo · 2 = LBTR Transacción · 3 = DVP · 4 = CCLV. La validación debe permitir solo valores 1-4 (error 14 si no).
